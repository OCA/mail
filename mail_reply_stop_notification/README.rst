Removes the recipients from the Email notification.

When the message is received as a reply to the existing Thread, Odoo
will create the notifications for the followers on that Thread. This
module removes the recipients that has set to be notified by Email. This
way notification emails are not generated. If the recipients should be
notified in Odoo - the module does not remove those recipients and
notifications in Odoo are created.

Configuration
=============

To enable/disable this module functionality, you need to:

-  Go to Settings > General Settings
-  Scroll to "Emails" section
-  Activate/Deactivate "Stop Email Notifications on Replies" boolean
   field > Save
