Odoo automatically adds record creators and message senders as followers of
document threads. While this is useful in many scenarios, it can lead to
cluttered chatter mailboxes and unwanted email notifications — especially on
high-volume models like Sales Orders, Purchase Orders, or Contacts.

This module lets you **selectively disable** that automatic follower behavior
on a per-model basis. It provides a single, centralized configuration page
(accessible only in Developer / debug mode) where system administrators can
choose exactly which models should skip Odoo's built-in auto-follower
subscription logic.
