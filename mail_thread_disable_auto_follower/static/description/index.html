Disable Mail Thread Auto-Follower

Selectively disable automatic follower subscriptions on specific Odoo models.

Overview

Odoo automatically adds record creators and message senders as followers of document threads. While useful in many scenarios, this can lead to cluttered chatter mailboxes and unwanted email notifications on high-volume models like Sales Orders, Purchase Orders, or Contacts.

This module provides a centralized configuration page (accessible only in Developer Mode) where administrators can choose which models should skip Odoo's auto-follower subscription logic.

Developed for Odoo 18. Community Association (OCA) standards compliant.
