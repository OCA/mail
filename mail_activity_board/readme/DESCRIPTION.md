This module extends the activity board to make it easier to browse activities
and navigate to their related documents.

It adds a **View Activities** button to the chatter, opening the board filtered
to the current record, and a **Document** link in the activity form and list views.

The board provides kanban, list, form, calendar, pivot and graph views, with
additional search options for the origin and deadline. Activities in the list
are color-coded according to whether they are overdue, due today or planned
for a later date.
